# 定期16 初始檔

記錄「定期十六」模式目前(存檔當下)的顯示邏輯與所有參數,做為之後調整的基準版本。對應程式碼位置：`applyRecentOnly()` 函式。

## 一、內容範圍

- 只保留「最新資料所在」那個區塊(其他 3 個區塊隱藏)。
- 該區塊裡只顯示**最近 16 期**已開獎資料。
- 最新一期之後,最多保留 **5 期空白(未開獎)期數**,多的隱藏。
- 保留區塊自己的右邊框關閉(`border-right:none`),避免跟外框的線疊在一起。

## 二、內容縮放(全螢幕顯示)

`.panels` 的 `transform` 改成**動態計算**,不是寫死的固定倍率：

1. 先把 `transform` 設為 `none`,量出內容「原始未縮放」的寬高(`naturalW`、`naturalH`)。
2. 用 `window.innerWidth / naturalW` 算出水平縮放倍率 `scaleX`。
3. 用 `window.innerHeight / naturalH` 算出垂直縮放倍率 `scaleY`。
4. 套用：
   ```js
   panels.style.transform = "translateX(-3%) scale(" + scaleX + ", " + scaleY + ")";
   ```

這樣不管手機螢幕尺寸多大,「16 方塊區」(含裡面所有文字、表格)都會剛好填滿當下螢幕。

## 三、外框(`.scroller`)位置與大小

量出縮放後的 `.panels` 實際寬高 `w`、`h`,依序疊加以下所有調整量,**全部是疊加關係,不是互相取代**：

| 項目 | 公式 | 說明 |
|---|---|---|
| 左邊往右縮 | `shrink = w * 0.01` | 右邊界不動,寬度扣掉,左邊留白補上 |
| 整體往左平移 | `shift = w * 0.001` | 疊加在 margin-left 上 |
| 往左平移 0.2% | `shiftLeft = w * 0.002` | 疊加 |
| 往右平移 0.2%(第一輪) | `shiftRight1 = w * 0.002` | 疊加 |
| 往上平移 0.2%(第一輪) | `shiftUp1 = h * 0.002` | 疊加 |
| 往右平移 0.3%(第二輪) | `shiftRight2 = w * 0.003` | 疊加 |
| 往上平移 0.3%(第二輪) | `shiftUp2 = h * 0.003` | 疊加 |
| 左邊界向右縮減 0.3% | `shrinkLeftOnly = w * 0.003` | 右邊界不動,margin-left 增加、width 同步減少 |
| 整體往下平移 | `h * 0.01` | 疊加在 margin-top 上 |

**最終計算公式：**

```js
scrollerEl.style.marginLeft =
  (shrink - shift - shiftLeft + shiftRight1 + shiftRight2 + shrinkLeftOnly) + "px";

scrollerEl.style.width =
  Math.ceil(w - shrink - shrinkLeftOnly) + "px";

scrollerEl.style.marginTop =
  (h * 0.01 - shiftUp1 - shiftUp2) + "px";

scrollerEl.style.height =
  Math.ceil(h) + "px";
```

## 四、外框顏色

`.scroller` 外框顏色在「定期」模式下改成紅色 `#e02020`(對應 CSS：`body.recent-only-mode .scroller{ border-color:#e02020; }`),框住整個「16 方塊區」(16 期資料 + 5 期空白 + 外框本身)。

## 五、離開「定期」時的還原

```js
panels.style.transform = "";
scrollerEl.style.width = "";
scrollerEl.style.marginLeft = "";
scrollerEl.style.marginTop = "";
scrollerEl.style.height = "";
```

離開後同步重新計算一次連接線位置(`renderConnections()`),避免線條停在「定期」模式底下的舊座標。

## 六、其他關聯設定

- 進入「定期」時,「彩券名稱」(`.img-game-tabs`)、「九宮鍵區」(`#img-hint`/`#draw-toolbar`)、`.img-overlay-title` 都會一起隱藏(`display:none`),不會跟「16 方塊區」搶畫面。
- `.panel-head` 標題列在定期模式下隱藏(`display:none`)。
